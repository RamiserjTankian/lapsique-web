# Imágenes Públicas

Este directorio contiene imágenes estáticas necesarias para el sitio web.

## Imágenes Requeridas

### og-default.jpg
**Dimensiones recomendadas:** 1200 x 630 px
**Formato:** JPG o PNG
**Peso máximo:** 1 MB

Esta es la imagen por defecto que se usará cuando se compartan enlaces del sitio en redes sociales (Facebook, Twitter, LinkedIn, WhatsApp, etc.) y no haya una imagen específica disponible para esa página.

**Recomendaciones para el diseño:**
- Usa el logo de lapsique.media
- Incluye el tagline: "Música electrónica, visuales y sets en vivo"
- Usa la estética monocromática del sitio
- Asegúrate de que el texto sea legible en miniaturas
- Considera que algunos servicios recortarán los bordes

### logo.png
**Formato:** PNG con transparencia
**Dimensiones recomendadas:** 512 x 512 px

Logo del sitio para uso en Schema.org structured data.

## Crear las Imágenes

Puedes crear estas imágenes usando herramientas como:
- Canva
- Figma
- Photoshop
- GIMP (gratuito)

O usar servicios online como:
- https://www.canva.com/
- https://www.figma.com/

## Nota Importante

Hasta que no agregues estas imágenes, el sistema intentará usarlas pero fallará graciosamente, mostrando la URL pero sin imagen.
